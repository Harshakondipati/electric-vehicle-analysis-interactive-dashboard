# Electric Vehicle Analysis Dashboard

An interactive **Electric Vehicle Analysis Dashboard** developed using **Microsoft Power BI** to analyze electric vehicle data and identify important trends, patterns, and insights.

## 📊 Project Overview

This project uses Power BI to transform electric vehicle data into an interactive dashboard. It provides a visual analysis of EV adoption, manufacturers, vehicle types, locations, and other important attributes available in the dataset.

The dashboard is designed to make EV data easier to understand through interactive visualizations, filters, KPIs, and analytical comparisons.

## 🎯 Objectives

- Analyze electric vehicle data.
- Understand EV distribution and adoption patterns.
- Compare different EV manufacturers.
- Analyze different vehicle types and models.
- Identify trends and patterns in the EV market.
- Build an interactive business intelligence dashboard.
- Convert raw data into meaningful visual insights.
